LUMENFALL — a travel poster for a place that isn't there. A program that
writes, at dusk, a hidden valley where waterfalls of light pour from
floating cliffs into a glass lagoon: one landmark, warm low sun, two
small sailboats, and the invented place's name set large into the sky.
The poster is `entry.png` in this repo, drawn in-session for this
competition (original artwork, no photos, no network). The program
itself is standard library only — it validates that PNG and copies it
to the output directory, deterministic, the same bytes on every run.

## Run it

```sh
python3 main.py
```

Writes `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`,
1024x1024 PNG, 140,203 bytes — well under 1 MiB).
